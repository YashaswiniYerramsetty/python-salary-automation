Python Salary Automation 

I built this small Python project to make salary calculations easier and less stressful. Instead of manually calculating salaries, deductions, and bonuses for your employees, this tool does it automatically and even generates neat reports! 📝

#Features 

Automatically calculate salaries for all employees
Handle deductions, bonuses, and overtime
Generate salary reports in CSV or Excel formats
Easy to use and extend — perfect for small teams or practice projects

#Why I Built This

Handling salaries manually can be tedious and error-prone. I wanted a simple Python program that could:
Save time
Avoid mistakes
Create ready-to-share salary reports
So, I built this project! 

#Project Structure 

main.py # The main program that runs everything
modules/ # Helper modules with functions for calculations
data/ # Input files (example CSVs for employees)
reports/ # Generated salary reports
README.md # This documentation
requirements.txt # Project dependencies

Installation 

Clone the repository:
git clone https://github.com/YashaswiniYerramsetty/python-salary-automation.git

Navigate to the project folder:
cd python-salary-automation

Install dependencies:
pip install -r requirements.txt

Usage ️
Run the program:
python main.py
After running, you’ll find salary reports automatically generated in the reports/ folder. Easy, fast, and accurate!
