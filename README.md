Python Salary Automation 

Hey there! I built this small Python project to make salary calculations less stressful.
Instead of manually crunching numbers for salaries, deductions, and bonuses, this little tool does it automatically and even generates neat reports!
---
## Features

* Automatically calculate salaries for all employees

* Handle deductions, bonuses, and overtime

* Generate salary reports in CSV or Excel formats

* Simple to use and easy to extend — perfect for small teams or practice projects
---
## Why I Built This

Honestly, calculating salaries by hand can be a pain — it’s tedious and easy to make mistakes.
I wanted a small Python program that could:

* Save time
 
* Avoid errors

* Generate ready-to-share salary reports

So… I built this project! 
---
## Project Structure

`main.py` – The main program that runs everything

`modules/` – Helper modules with functions for calculations

`data/` – Example CSVs for employee input

`reports/` – Generated salary reports

`README.md` – Yep, this documentation

`requirements.txt` – All the dependencies you need
---
## Installation 

Clone the repository:
git clone https://github.com/YashaswiniYerramsetty/python-salary-automation.git

Navigate to the project folder:
cd python-salary-automation

Install dependencies:
pip install -r requirements.txt
---
## Usage ️
Run the program:
 python main.py
After running, you’ll find salary reports automatically generated in the reports/ folder. Easy, fast, and accurate!
